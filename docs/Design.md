# Nova Launcher — UI 设计

## 设计目标

采用 Windows 11 Minimal Glass UI。深色、克制、清晰，让用户快速定位并启动应用。以下尺寸与颜色是初始设计提案，实际窗口验证后可调整，不表示已有界面实现。

## 布局

- 建议初始窗口 1120 × 720 DIP，最小尺寸 800 × 560 DIP；保留拖动区和标准最小化、最大化、关闭行为。
- 左侧导航宽约 200 DIP，首期包含品牌区与全部应用入口；为后续收藏和底部设置预留布局，功能未实现前不显示入口。
- 右侧顶部预留页面标题与搜索区，下方为可滚动大图标网格。列数随可用宽度变化，避免水平滚动。
- 内容外边距 24 DIP，卡片间距 16 DIP；建议卡片 128 × 136 DIP，图标 56 × 56 DIP。
- 应用名称最多显示两行，溢出省略并提供完整名称提示；图标缺失时显示统一占位图标。

半透明材质叠加后仍需实际检查文字对比度。图标保持原有识别性，不使用 Emoji 代替应用图标。

## 背景与材质

主窗口优先评估 Mica 风格，浮层优先评估 Acrylic 风格。两者不是普通透明度的同义词：Mica 侧重桌面背景色调融合，Acrylic 侧重半透明模糊。具体系统 API、WPF 适配方式和系统版本条件在工程阶段验证。

保持文字与图标不透明；通过背景层和语义画刷控制玻璃观感。禁止简单降低整个窗口 Opacity。系统关闭透明效果、进入高对比度或材质不可用时，自动使用实色背景；高对比度优先采用系统颜色。

## 交互与状态

| 状态 | 表现 |
| --- | --- |
| Normal | 低对比表面，名称清晰可读 |
| Hover | 表面轻微提亮，约 140 ms EaseOut；可轻微上移 2 DIP |
| Pressed | 约 80 ms 反馈，可缩放至 0.98，不改变网格布局 |
| Keyboard focus | 清晰的强调色焦点边框，不依赖 Hover |
| Selected | 导航标记与背景同时变化，和键盘焦点区分 |
| Busy / Disabled | 明确状态提示，阻止重复启动，不隐藏名称 |
| Empty / Error | 简洁原因及可操作入口，例如添加应用或修正失效路径 |

启动采用单击或聚焦后 Enter；Tab 按逻辑顺序移动焦点。后续网格支持方向键导航，输入框中的方向键保持文本编辑语义。动画使用视觉变换，避免触发布局反复计算；尊重系统减少动画设置。

实际验收覆盖鼠标、键盘、100% / 150% / 200% DPI、最小窗口、长中文名称、空列表、图标缺失、路径失效及关闭透明效果。

## ui-ux-pro-max 接入

技能已安装至 Codex 用户技能目录，SKILL.md 可读取，辅助脚本的 WPF 检索已验证通过。来源、固定版本、路径与复现命令见 [SkillIntegration.md](SkillIntegration.md)。

后续设计工作读取技能入口，输入 Windows 桌面、深色、Minimal Glass、左导航、大图标及材质回退等约束。通用视觉建议先映射为本文件中的设计参数；实现指导显式选择 wpf，不改用网页技术栈。

当前仅完成接入，没有生成设计系统、XAML 或其他 UI 代码。技能输出属于建议，项目规则和用户当前指令优先。用户明确启动设计或编码阶段后，再执行相应工作。
