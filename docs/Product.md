# Nova Launcher — 产品定义

## 8.4 实时透明背景（实验性，8.4.3最终验收通过）

Settings外观提供“玻璃模式（实验性）”（8.4.1更名）：实时显示窗口后方内容，提供玻璃遮罩强度；不提供背景Blur。Default、DesktopWallpaper、CustomImage继续保留，DesktopWallpaper仅表示静态壁纸文件。透明模式可立即关闭，不支持时回退默认。数据结构、既有导航与搜索语义不变。证据、性能及手工验收边界见 [Transparency-8.4.md](Transparency-8.4.md)。

## 8.3 主界面信息架构（当前规范，已验收）

默认主页面为“全部应用”，只展示一份完整应用集合。分类负责筛选浏览，收藏负责收藏应用，最近使用按LastLaunchTime倒序展示真正启动过的应用，Ctrl+K负责快速启动。主页面不再重复展示收藏/最近使用，也没有“查看全部”链接。

```text
Nova Launcher
Sidebar
├── All Applications（全部应用）
├── Categories（动态分类）
├── Favorites（收藏）
├── Recent（最近使用）
└── Profile（底部头像）
Global: Quick Launcher
Settings: Profile Flyout → Settings
```

全部应用保留EXE/LNK拖入、启动、Hover统计和右键管理。空集合显示原始“+ / 请将文件拖拽至此 / 支持 .exe 和 .lnk”，搜索入口保留，隐藏空列表标题。收藏空状态为“还没有收藏应用 / 右键应用即可添加到收藏”；最近使用空状态不变。Quick Launcher打开、关闭或成功启动不改变当前页面。

Settings启动选项为“全部应用 / 收藏 / 最近使用”。既有持久化值`StartupPage=Home`继续表示默认全部应用，不变更数据库或用户设置。默认分类“应用”与“全部应用”语义接近，本轮保留其现有名称和Id，后续可评估“工具/常用工具/其他应用”，不擅自改名。

应用超过100项时，全部应用主列表保留8.2首批40、SystemIdle每批20的渐进呈现；完整应用集合与搜索索引独立于已渲染卡片。下文阶段记录只保留其仍有效功能，旧首页语义由本节取代。

## 7.3 拼音与首字母搜索（已验收）

Quick Launcher 支持微信 → weixin/wx、记事本 → jishiben/jsb、QQ音乐 → qqyinyue/qqyy，以及中文、英文、数字混合名称。名称原文忽略大小写的完全/前缀/包含匹配优先；额外提供忽略空白的名称匹配，再按全拼完全/前缀、首字母完全/前缀、全拼包含、首字母包含排序。同档仍按最近启动、DisplayName、Id 排序；每个应用只出现一次。

加载/导入时建立内存 Key，重命名立即替换、移除立即释放；查询不转换拼音，不读写 SQLite。仅去除派生 Key 和 Query 中的空白，保留 +、.、-、_、括号与数字。中文 Query 不强制转拼音；未知字符仍可通过原名称匹配。采用离线词典默认读音，不承诺语义级多音字消歧或所有生僻字覆盖。

保持 7.2 Overlay、Top8、空 Query Recent Top6 / Favorites fallback、键盘、鼠标与 IME 防护。无 Schema/Migration；不扩展在线搜索或历史。依赖、验证、性能及截图见 [PinyinSearch-7.3.md](PinyinSearch-7.3.md)。以下为历史阶段。

## 7.2 Quick Launcher（已验收）

7.2 用窗口内 Quick Launcher 浮层替代 7.1 的 Workspace 搜索。顶部保留按钮式搜索入口，Ctrl+K 打开同一浮层；重复 Ctrl+K 聚焦并全选。Settings 中直接叠加面板，不切换页面。关闭或成功启动后清空 Query，WorkspaceMode、SelectedCategory、Sidebar 及原页面均保留。

空 Query 优先显示最近使用 Top6；无最近记录则显示收藏 Top6；两者都没有时提示输入应用名称。非空 Query 复用 ApplicationSearchService，按原匹配排序取 Top8。第一项默认选中，Query 变化重置到首项，↑↓不循环，Enter 启动当前项，Esc/外部点击关闭；鼠标整行单击启动。启动失败保留面板与错误提示。结果行显示图标、名称、分类，不提供右键管理菜单，原 Workspace 卡片的管理功能保持不变。

仅内存搜索，无 Schema/Migration 或历史持久化。7.1 的 SearchMode/Grid/专用空状态已移除，只有一套 Query。实现、IME 和性能验证见 [QuickLauncher-7.2.md](QuickLauncher-7.2.md)。以下为历史阶段。

## 7.1 全局应用搜索（已验收）

Home、Category、Favorites、Recent 的 Workspace 顶部提供应用搜索；Settings 隐藏。窗口内 Ctrl+K 聚焦并全选已有文字，Settings 下先恢复上一次应用页（无记录则 Home）。非空 Trim Query 进入临时 Search 模式，搜索全部已加载应用；清空、Clear 或搜索框 Esc 恢复进入前页面及分类，Sidebar 保留原选中项。空文本 Esc 仅释放焦点。

仅匹配 DisplayName，OrdinalIgnoreCase Contains，支持中文、英文、数字；完全匹配优先于前缀，再到包含；同级按 LastLaunchTime 降序、名称和 Id 稳定排序。Enter 通过原 LaunchCommand 启动首项，保留搜索上下文；Tab/Shift+Tab 可访问结果。7.1 未增加 Up/Down 选择。

搜索结果复用完整 ApplicationCardView，右键管理、启动统计、匹配导入与移除实时同步。Query 不持久化，搜索不查询 SQLite，不修改 Schema 或 Migration；不增加拼音、纠错、系统扫描、网络搜索或历史。实现与验收证据见 [Search-7.1.md](Search-7.1.md)。以下为历史阶段。

## 6.5 应用编辑（当前范围）

Application Context Menu 增加重命名、更换图标、条件显示的恢复默认图标，以及末尾危险色“从启动器移除”。重命名 Trim 后限 1–48 字符；支持 PNG/JPG/JPEG/BMP/ICO。操作成功后 Home、分类、收藏和最近使用立即同步。移除通过 Nova 内部确认，只删除启动器记录与自有资源，真实程序和快捷方式保留，可再次导入。

沿用 6.4 菜单视觉与 6.3 背景实现。详见 [6.5 交付记录](ApplicationEditing-6.5.md)。以下为历史阶段。

## 6.4 分类入口与卡片菜单（当前范围）

Sidebar 仅保留动态分类导航，分类创建迁入 Settings 的“分类管理”Section。列表展示全部现有分类，内联编辑沿用 Trim、1–24 字符、重复校验、Enter 创建、Esc 取消与 Toast；保存成功立即更新 Sidebar，重启恢复。本轮不实现重命名、删除、排序或分类图标编辑。

所有页面共用的 ApplicationCard 移除可见收藏星标和 Hover 分类按钮。右键菜单提供收藏/取消收藏、移动到分类（含未分类）、打开目标程序文件位置、只读应用信息。左键和 Enter/Space 保持启动，右键和菜单操作不启动；支持 Shift+F10、Context Menu 键、方向键、Enter、Esc。Favorites 及 Home 收藏 Section 继续实时更新，空状态改为“右键应用卡片即可收藏”。

基于已验收 6.3，不更改背景实现、主题、Experimental DesktopBackdrop 或数据库 Schema；不自动 commit。详见 [6.4 交付记录](Management-6.4.md)。以下为历史阶段。

## 6.3 背景与外观（当前范围）

Settings → 外观 → 背景在原单页中展开，支持 Default、DesktopWallpaper、CustomImage；遮罩 20–95%（默认 72%）、模糊 0–30（默认 12）、填充/适应与恢复默认。主题保持 Light。桌面模式读取 Windows 主/系统静态壁纸并提供手动刷新，不捕获动态桌面、其他程序或每显示器独立壁纸。自定义 PNG/JPG/JPEG/BMP 转换为本地 PNG，取消与失败保留旧图，重启恢复；缺失/损坏背景仅会话回退默认。保持 6.2 设置与第五阶段功能，不自动 commit。

详见 [6.3 实现与验证记录](Appearance-6.3.md)。以下为历史阶段。

## 6.2 设置中心（当前范围，已验收）

头像 Profile Flyout 的“设置”进入独立单页工作区；外观、启动与窗口、数据与存储、关于四段。两个窗口记忆开关默认开启；启动页支持 Home（默认）/ Recent / Favorites，修改即时保存、失败回滚提示。正常退出保存窗口边界，重启恢复并校验屏幕可见性；关闭记忆时使用默认尺寸/位置。

提供当前数据目录、数据库路径、Windows Shell 打开目录和程序集版本。背景 Default、主题 Light 仅为 UI 与数据结构预留，不切换背景/主题，不实现 6.3 特性。保护 6.1 资料及第五阶段功能。6.2 已通过用户验收，按授权完成收尾提交，不开始下一阶段。字段、实现与验证见 [6.2 交付记录](Settings-6.2.md)。下文为历史阶段记录。

## 6.1 本地个人资料（当前范围）

提供单一本地 Profile：修改名称、更换或恢复默认头像，重启后恢复。Sidebar 底部只常驻圆形头像，Tooltip 显示名称；原独立设置导航已移除，设置仅从头像 Flyout 进入占位页。首页、分类、收藏、最近使用与应用操作保持原行为。

名称首尾 Trim，允许 1–24 个 UTF-16 字符；空名称和超长名称用现有 Toast 提示。头像支持 PNG/JPG/JPEG/BMP，转换为 Nova 自有 Profile 目录中的 PNG；取消选择不改变资料，失败保留旧状态。无登录、网络账户、多用户、在线头像或真正设置功能。

6.1 基于 08fe8615b206550cb77dc03fae416549541186cc 实现，已通过最终验收并获授权收尾提交。下文为历史阶段范围。

## 5.4 历史页面（8.3已替代）

原聚合页面已取消，当前结构以8.3为准；收藏与最近使用数据和独立页面继续保留。

## 5.3 最近使用系统

“最近使用”显示 LastLaunchTime 非空的应用，按实际时间从新到旧排列；再次成功启动后立即移至相应位置。相同时间按名称、应用 Id 稳定排序。首次从首页启动的应用会进入 Recent，未启动的新导入应用不会出现；曾启动但文件已失效的应用仍保留，点击沿用原失败提示。

Home、Category、Favorites、Recent 四种模式互斥；Recent 不修改原应用集合顺序，也不改变分类或收藏状态。离开 Recent 恢复原顺序，重启从 SQLite 中已有 LastLaunchTime 恢复排序。继续复用现有卡片、星标、分类入口和 Hover 时间格式，不增加常态统计文字。

无记录时显示时钟图标、“最近还没有启动过应用”及“启动应用后，它会出现在这里”。不新增数据库字段或 Migration，不实现时长/周期统计、图表、编辑/删除、分类增强、首页聚合、用户资料、设置或背景功能。当前以本节为准，以下为历史阶段记录；5.3 已通过验收，最终收尾提交已获授权。

## 5.2 应用收藏系统

卡片右上角星标支持收藏/取消收藏，状态保存 SQLite 并在重启后恢复。未收藏为空心弱色星标，Hover/键盘聚焦增强；已收藏为常显实心星标。星标是独立按钮，点击或 Enter/Space 不启动应用；卡片主体保留原启动行为。成功静默反馈，失败显示“收藏状态保存失败”并保留原状态。

首页显示全部应用，分类显示对应 CategoryId，收藏显示 IsFavorite=true，三种模式互斥。分类与收藏独立，取消收藏不改变分类。收藏页取消收藏立即移除当前卡片，源集合保留；空状态为星形图标、“还没有收藏应用”和“点击应用卡片上的星标即可收藏”。所有页面继续支持拖入导入，新应用默认未分类、未收藏，因此从收藏页导入的应用不会自动出现。

范围不含最近使用页面、首页聚合、应用编辑/删除、分类删除/重命名、排序、用户、设置或自定义背景。5.2 已通过验收，最终收尾提交已获授权。以下 5.1 及更早章节保留对应阶段历史范围，当前行为以本节为准。

## 5.1 应用分类系统

当前已实现单应用单分类：用户可创建普通分类、通过卡片“分类”浮层指定归属，再从侧栏筛选。分类及归属立即保存 SQLite，重启恢复。“游戏”“应用”是 Migration 首次插入的普通记录，不是不可变系统分类；自定义项使用统一文件夹图标。

侧栏保留首页、游戏、应用、收藏、最近使用、设置，分类项来自数据库集合；“＋ 新建分类”位于分类之后。内联输入支持 Enter 创建、Esc 取消，名称 Trim 后为 1–24 个 UTF-16 字符，禁止完全同名（区分大小写），SQLite 唯一索引兜底。重复或保存失败复用 Toast，编辑器保留错误信息。

首页显示全部应用，分类导航只显示对应 CategoryId；收藏、最近使用和设置继续保留原有占位行为。CategoryId=null 表示未分类，首页仍可见；新导入 EXE/LNK 默认未分类，不强制弹出分类选择。卡片分类入口在 Hover 或键盘焦点时显示，提供已有分类与“未分类”。保存成功后更新卡片和筛选，失败保留原分类，不出现内存与数据库归属不一致。

本阶段不提供收藏、最近使用页面、应用或分类排序、分类图标自定义、分类重命名、分类删除、应用删除/编辑或完整右键菜单。后续规划和历史阶段记录见下文。

## 项目定位

面向 Windows 11 用户的轻量本地应用启动器，以 Minimal Light Glass 界面集中展示常用应用，减少查找与启动步骤。使用 C#、.NET 9、WPF、MVVM 和 SQLite，不依赖账号或云服务。

本文定义第一版本的规划基线。4.1 已完成拖放 .exe / .lnk 与卡片；用户于 2026-10-15 授权 4.2 增加应用启动、会话内次数/时间和 Hover 状态。4.3 已授权实现 SQLite 应用与统计持久化。其余第一版本用例仍为后续规划。

## 用户场景

| 场景 | 用户目标 | 预期结果 |
| --- | --- | --- |
| 首次使用 | 把常用程序加入启动器 | 选择本地 exe，确认名称后显示图标卡片 |
| 日常工作 | 快速找到并打开应用 | 浏览大图标或搜索名称，单击或按 Enter 启动 |
| 应用迁移 | 修复移动后的程序路径 | 编辑路径后正常启动，保留已有名称 |
| 清理列表 | 移除不再使用的启动项 | 只移除启动器记录，不卸载或删除原程序 |
| 再次打开 | 继续使用已整理的列表 | 从 SQLite 恢复应用记录 |
| 键盘或高 DPI 使用 | 无障碍操作与清晰阅读 | 焦点可见、缩放清晰，关闭透明效果仍可操作 |

| 功能 | 范围与验收条件 |
| --- | --- |
| 主窗口 | 可调整宽度的左侧导航、右侧完整启动工作区；浅色玻璃材质及实色回退 |

## 后续扩展方向

1. 效率：收藏、分类、拖动排序、最近使用、全局快捷键与托盘。
2. 导入：开始菜单扫描、快捷方式和打包应用支持、配置导入导出。
3. 个性化：主题、图标大小、布局密度和自定义图标。
4. 长期探索：插件能力与可选同步；单独评估数据契约、性能和维护成本。

扩展进入开发前，应更新本文的范围与验收条件，并同步 Design.md 和 Architecture.md。
