# Nova Launcher — 产品定义

## 6.3 背景与外观（当前范围）

Settings → 外观 → 背景在原单页中展开，支持 Default、DesktopWallpaper、CustomImage；遮罩 20–95%（默认 72%）、模糊 0–30（默认 12）、填充/适应与恢复默认。主题保持 Light。桌面模式读取 Windows 主/系统静态壁纸并提供手动刷新，不捕获动态桌面、其他程序或每显示器独立壁纸。自定义 PNG/JPG/JPEG/BMP 转换为本地 PNG，取消与失败保留旧图，重启恢复；缺失/损坏背景仅会话回退默认。保持 6.2 设置与第五阶段功能，不自动 commit。

详见 [6.3 实现与验证记录](Appearance-6.3.md)。以下为历史阶段。

## 6.2 设置中心（当前范围，已验收）

头像 Profile Flyout 的“设置”进入独立单页工作区；外观、启动与窗口、数据与存储、关于四段。两个窗口记忆开关默认开启；启动页支持 Home（默认）/ Recent / Favorites，修改即时保存、失败回滚提示。正常退出保存窗口边界，重启恢复并校验屏幕可见性；关闭记忆时使用默认尺寸/位置。

提供当前数据目录、数据库路径、Windows Shell 打开目录和程序集版本。背景 Default、主题 Light 仅为 UI 与数据结构预留，不切换背景/主题，不实现 6.3 特性。保护 6.1 资料及第五阶段功能。6.2 已通过用户验收，按授权完成收尾提交，不开始下一阶段。字段、实现与验证见 [6.2 交付记录](Settings-6.2.md)。下文为历史阶段记录。

## 6.1 本地个人资料（当前范围）

提供单一本地 Profile：修改名称、更换或恢复默认头像，重启后恢复。Sidebar 底部只常驻圆形头像，Tooltip 显示名称；原独立设置导航已移除，设置仅从头像 Flyout 进入占位页。首页、分类、收藏、最近使用与应用操作保持原行为。

名称首尾 Trim，允许 1–24 个 UTF-16 字符；空名称和超长名称用现有 Toast 提示。头像支持 PNG/JPG/JPEG/BMP，转换为 Nova 自有 Profile 目录中的 PNG；取消选择不改变资料，失败保留旧状态。无登录、网络账户、多用户、在线头像或真正设置功能。

6.1 基于 08fe8615b206550cb77dc03fae416549541186cc 实现，已通过最终验收并获授权收尾提交。下文为历史阶段范围。

## 5.4 首页聚合 Dashboard

首页依次显示最近使用（Top 6）、收藏（Top 6）、全部应用。最近使用仅包含启动时间非空的应用，按时间倒序与稳定次级顺序排列；收藏及全部应用保持原应用顺序。前两段为空时整段隐藏，没有应用时沿用拖入 .exe / .lnk 的空状态。

所有区域共享现有卡片实例：启动后最近使用即时重排，收藏成功后即时增删和补位，取消收藏仍保留全部应用中的卡片。导入默认只进入全部应用。两个“查看全部”进入原 Recent/Favorites 页面并同步 Sidebar 选中；分类、收藏、最近使用独立页面及设置占位不变。

本阶段无数据库字段、Migration 或新依赖，不扩展其他业务。当前行为以本节为准，以下为历史阶段记录。5.4 已通过用户验收，最终收尾提交已获授权，不开始下一阶段。

## 5.3 最近使用系统

“最近使用”显示 LastLaunchTime 非空的应用，按实际时间从新到旧排列；再次成功启动后立即移至相应位置。相同时间按名称、应用 Id 稳定排序。首次从首页启动的应用会进入 Recent，未启动的新导入应用不会出现；曾启动但文件已失效的应用仍保留，点击沿用原失败提示。

Home、Category、Favorites、Recent 四种模式互斥；Recent 不修改原应用集合顺序，也不改变分类或收藏状态。离开 Recent 恢复原顺序，重启从 SQLite 中已有 LastLaunchTime 恢复排序。继续复用现有卡片、星标、分类入口和 Hover 时间格式，不增加常态统计文字。

无记录时显示时钟图标、“最近还没有启动过应用”及“启动应用后，它会出现在这里”。不新增数据库字段或 Migration，不实现时长/周期统计、图表、编辑/删除、分类增强、首页聚合、用户资料、设置或背景功能。当前以本节为准，以下为历史阶段记录；5.3 已通过验收，最终收尾提交已获授权。

## 5.2 应用收藏系统

卡片右上角星标支持收藏/取消收藏，状态保存 SQLite 并在重启后恢复。未收藏为空心弱色星标，Hover/键盘聚焦增强；已收藏为常显实心星标。星标是独立按钮，点击或 Enter/Space 不启动应用；卡片主体保留原启动行为。成功静默反馈，失败显示“收藏状态保存失败”并保留原状态。

首页显示全部应用，分类显示对应 CategoryId，收藏显示 IsFavorite=true，三种模式互斥。分类与收藏独立，取消收藏不改变分类。收藏页取消收藏立即移除当前卡片，源集合保留；空状态为星形图标、“还没有收藏应用”和“点击应用卡片上的星标即可收藏”。所有页面继续支持拖入导入，新应用默认未分类、未收藏，因此从收藏页导入的应用不会自动出现。

范围不含最近使用页面、首页聚合、应用编辑/删除、分类删除/重命名、排序、用户、设置或自定义背景。5.2 已通过验收，最终收尾提交已获授权。以下 5.1 及更早章节保留对应阶段历史范围，当前行为以本节为准。

## 5.1 应用分类系统

当前已实现单应用单分类：用户可创建普通分类、通过卡片“分类”浮层指定归属，再从侧栏筛选。分类及归属立即保存 SQLite，重启恢复。“游戏”“应用”是 Migration 首次插入的普通记录，不是不可变系统分类；自定义项使用统一文件夹图标。

侧栏保留首页、游戏、应用、收藏、最近使用、设置，分类项来自数据库集合；“＋ 新建分类”位于分类之后。内联输入支持 Enter 创建、Esc 取消，名称 Trim 后为 1–24 个 UTF-16 字符，禁止完全同名（区分大小写），SQLite 唯一索引兜底。重复或保存失败复用 Toast，编辑器保留错误信息。

首页显示全部应用，分类导航只显示对应 CategoryId；收藏、最近使用和设置继续保留原有占位行为。CategoryId=null 表示未分类，首页仍可见；新导入 EXE/LNK 默认未分类，不强制弹出分类选择。卡片分类入口在 Hover 或键盘焦点时显示，提供已有分类与“未分类”。保存成功后更新卡片和筛选，失败保留原分类，不出现内存与数据库归属不一致。

本阶段不提供收藏、最近使用页面、应用或分类排序、分类图标自定义、分类重命名、分类删除、应用删除/编辑或完整右键菜单。后续规划和历史阶段记录见下文。

## 项目定位

面向 Windows 11 用户的轻量本地应用启动器，以 Minimal Light Glass 界面集中展示常用应用，减少查找与启动步骤。使用 C#、.NET 9、WPF、MVVM 和 SQLite，不依赖账号或云服务。

本文定义第一版本的规划基线。4.1 已完成拖放 .exe / .lnk 与卡片；用户于 2026-10-15 授权 4.2 增加应用启动、会话内次数/时间和 Hover 状态。4.3 已授权实现 SQLite 应用与统计持久化。其余第一版本用例仍为后续规划。

## 用户场景

| 场景 | 用户目标 | 预期结果 |
| --- | --- | --- |
| 首次使用 | 把常用程序加入启动器 | 选择本地 exe，确认名称后显示图标卡片 |
| 日常工作 | 快速找到并打开应用 | 浏览大图标或搜索名称，单击或按 Enter 启动 |
| 应用迁移 | 修复移动后的程序路径 | 编辑路径后正常启动，保留已有名称 |
| 清理列表 | 移除不再使用的启动项 | 只移除启动器记录，不卸载或删除原程序 |
| 再次打开 | 继续使用已整理的列表 | 从 SQLite 恢复应用记录 |
| 键盘或高 DPI 使用 | 无障碍操作与清晰阅读 | 焦点可见、缩放清晰，关闭透明效果仍可操作 |

## 第一版本功能列表

| 功能 | 范围与验收条件 |
| --- | --- |
| 主窗口 | 可调整宽度的左侧导航、右侧完整启动工作区；浅色玻璃材质及实色回退 |
| 添加应用 | 手动选择本地 exe，保存名称、路径及可选参数、工作目录；无效输入有明确提示 |
| 编辑与移除 | 修改启动信息；移除前确认，只删除本地记录 |
| 图标与名称 | 从程序提取图标，失败时显示占位图；长名称可查看完整内容 |
| 搜索 | 按显示名称筛选，忽略大小写；空关键词恢复全部，零结果有提示 |
| 启动 | 单击或 Enter 启动；执行期间避免重复触发，失败说明原因 |
| 持久化 | SQLite 保存应用条目，重启后恢复；数据库异常不静默清空数据 |
| 基础交互 | Hover、Pressed、键盘焦点反馈，尊重系统减少动画设置 |
| 状态反馈 | 覆盖首次空列表、搜索无结果、加载中、无效路径及图标缺失 |

当前导入支持本地 exe 和指向有效 exe 的快捷方式；URI、脚本、文档、文件夹和打包应用快捷方式不支持。收藏、分类、自动扫描、托盘、全局热键和云同步不纳入 4.1 验收。六个侧栏入口仍仅改变选中状态，不过滤卡片，也不实现对应业务功能。4.2 支持单击或 Enter/Space 启动，成功后更新 LaunchCount / LastLaunchTime，失败不改变统计；同一卡片至少 400ms 启动保护。Hover 或键盘聚焦显示状态，正常状态保持图标和名称。4.3 使用 SQLite 保存应用、次数、时间和图标缓存路径，重启后恢复；不实现收藏、分类、删除、编辑、运行时长或最近使用页面。
