# Nova Launcher — 产品定义

## 项目定位

面向 Windows 11 用户的轻量本地应用启动器，以深色 Minimal Glass 界面集中展示常用应用，减少查找与启动步骤。使用 C#、.NET 9、WPF、MVVM 和 SQLite，不依赖账号或云服务。

本文定义第一版本的规划基线，不代表功能已经实现，也不授权本阶段开始编码。

## 用户场景

| 场景 | 用户目标 | 预期结果 |
| --- | --- | --- |
| 首次使用 | 把常用程序加入启动器 | 选择本地 exe，确认名称后显示图标卡片 |
| 日常工作 | 快速找到并打开应用 | 浏览大图标或搜索名称，单击或按 Enter 启动 |
| 应用迁移 | 修复移动后的程序路径 | 编辑路径后正常启动，保留已有名称 |
| 清理列表 | 移除不再使用的启动项 | 只移除启动器记录，不卸载或删除原程序 |
| 再次打开 | 继续使用已整理的列表 | 从 SQLite 恢复应用记录 |
| 键盘或高 DPI 使用 | 无障碍操作与清晰阅读 | 焦点可见、缩放清晰，关闭透明效果仍可操作 |

## 第一版本功能列表

| 功能 | 范围与验收条件 |
| --- | --- |
| 主窗口 | 左侧导航、右侧大图标网格；深色背景、玻璃材质及实色回退 |
| 添加应用 | 手动选择本地 exe，保存名称、路径及可选参数、工作目录；无效输入有明确提示 |
| 编辑与移除 | 修改启动信息；移除前确认，只删除本地记录 |
| 图标与名称 | 从程序提取图标，失败时显示占位图；长名称可查看完整内容 |
| 搜索 | 按显示名称筛选，忽略大小写；空关键词恢复全部，零结果有提示 |
| 启动 | 单击或 Enter 启动；执行期间避免重复触发，失败说明原因 |
| 持久化 | SQLite 保存应用条目，重启后恢复；数据库异常不静默清空数据 |
| 基础交互 | Hover、Pressed、键盘焦点反馈，尊重系统减少动画设置 |
| 状态反馈 | 覆盖首次空列表、搜索无结果、加载中、无效路径及图标缺失 |

第一版本只支持手动维护本地 exe。收藏、分类、自动扫描、快捷方式、URI、打包应用、托盘、全局热键和云同步不纳入首期验收。第三阶段按用户要求展示首页、游戏、应用、收藏、最近使用和设置六个导航入口；目前只切换占位标题，不代表对应业务功能已实现。

## 后续扩展方向

1. 效率：收藏、分类、拖动排序、最近使用、全局快捷键与托盘。
2. 导入：开始菜单扫描、快捷方式和打包应用支持、配置导入导出。
3. 个性化：主题、图标大小、布局密度和自定义图标。
4. 长期探索：插件能力与可选同步；单独评估数据契约、性能和维护成本。

扩展进入开发前，应更新本文的范围与验收条件，并同步 Design.md 和 Architecture.md。
